# Conventions & Gotchas

- **Tailwind v4 + daisyUI v5:** no `tailwind.config.js`/`postcss.config.js`. Config lives in `frontend/src/assets/main.css`: `@import "tailwindcss"`, `@plugin "daisyui"`, the custom `financer` theme, and tokens in an `@theme` block. Use tokens (`bg-surface`, `text-income`, `bg-primary-500`) — never inline hex or `bg-[#...]` arbitrary values. daisyUI v5 notes: `input`/`select` bordered by default (no `-bordered`), `form-control`/`label-text` gone, `btn-group` replaced by `join` + `join-item`.
- **DB:** SQLite via `glebarez/sqlite` (pure Go, no CGO) with WAL. The schema is a **single baseline** in `db/migrations/000001_initial_schema.up.sql`, embedded in the binary and applied at boot on a fresh database. There is no upgrade path from a pre-0.6 (Rust-era) database — delete the SQLite file and start fresh.
- **Config:** env-only, no config file. `FINANCER_*` vars with built-in defaults: `ADDR`, `DATA_DIR`, `STATIC_DIR`, `DOMAIN_URL`, `JWT_SECRET` (**required**), `TIMEZONE`, `SQLITE_PATH`, `SECRET_KEY` (mail credentials), `MAIL_POLL_SECS`, `ALLOW_INSECURE_HTTP`. Frontend API URL: `VITE_API_URL` (dev only; production is same-origin or `DOMAIN_URL`-injected).
- **`occurredAt` storage:** stored as UTC strings in the Go-driver layout (`"YYYY-MM-DD HH:MM:SS +0000 UTC"`); the wire returns RFC3339 in the configured timezone. `internal/time.ParseUTC` also accepts bare and RFC3339 forms, because the SQLite driver returns `time.Time` for `TIMESTAMP` columns scanned into strings.
- **Debt accounts** (`CREDIT_CARD`, `LOAN`) count as real spending in analytics; non-debt transfers are excluded via `transfer_links`.
- **Commits:** Conventional Commits (`feat:`/`fix:`/`docs:`/`refactor:`/`test:`/`chore:`/`perf:`); one logical change per commit.
- **Never force-push.** Update a PR branch by merging `main` into it (`git merge origin/main`) and pushing normally. No rebasing a published branch and no `git push --force`/`--force-with-lease`.
- **Markdown filenames:** project `.md` docs use ALL_CAPS filenames (`README.md`, `AGENTS.md`, `ROADMAP.md`, `UI_STANDARDS.md`, `UI_TEST_CHECKLIST.md`, `DEPLOY.md`). Tooling-generated docs keep their generator's convention.
- **PR titles:** Conventional Commits with a scope, e.g. `feat(backend): rewrite the API in Go` or `ci: build and publish the Go backend`.
- **PR bodies:** fill in `.github/PULL_REQUEST_TEMPLATE.md` and pass it with `gh pr create/edit --body-file <path>`. Never pass the body inline in the shell (PowerShell mangles escapes/quotes).
